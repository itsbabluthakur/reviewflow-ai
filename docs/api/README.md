# API Documentation

## Purpose

Detailed, generated, or example-heavy API reference material that supports the root [`API.md`](../../API.md) contract. `API.md` remains the authoritative REST API specification; this directory holds generated output and worked examples.

## What belongs here

* Generated OpenAPI/Swagger specs and their rendered HTML/JSON output.
* Request/response examples too verbose for `API.md`.
* Client integration guides (e.g. "using the ReviewFlow AI API from Node").

## What should NOT be placed here

* The canonical endpoint list, status codes, or design rules — those live in root `API.md` and must stay in sync with the actual implementation.
* Authentication or security requirements — those belong in `SECURITY.md`, referenced from here where relevant.

_No generated API artifacts exist yet — this directory is scaffolded ahead of Phase 14 (API & Webhooks) in [`ROADMAP.md`](../../ROADMAP.md)._
